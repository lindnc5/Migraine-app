# Migraine Log

A super simple iPhone web app for tracking migraines, Zolmitriptan, and Advil.

- Opens to today with three big buttons; tapping one logs it with the current date and time.
- Month calendar shows colored dots for each day (red = migraine, purple = Zolmitriptan, blue = Advil).
- Tap any past day to see or add entries; ✕ deletes an entry.
- Data is stored only on the phone. Use **Backup / Restore** to save a copy.

Install: open the GitHub Pages link in Safari → Share → **Add to Home Screen**.
