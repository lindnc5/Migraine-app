# Migraine Log

A super simple iPhone web app for tracking migraines, Zolmitriptan, and Advil.

- Opens to today with three big buttons; tapping one logs it with the current date and time.
- Month calendar shows colored dots for each day (red = migraine, purple = Zolmitriptan, blue = Advil).
- Tap any past day to see or add entries.
- Tap a logged entry to change its time, add a note, or delete it.
- **Buttons** tab: add, rename, recolor, reorder, or remove medicine buttons (removed ones keep their history and can be restored). Backup / Restore lives here too.
- **End times** for migraines: an "ongoing" banner with one-tap **End now** (defaults to now, adjustable). Migraines that run past midnight mark every day they cover.
- **Tags** on migraines (e.g. Low sleep, Pressure): type to get suggestions or pick from your most-used tags; manage the list on the Buttons tab.
- **Summary** tab: migraine and medicine days for a month, 3 months, or a year; a 12-month chart; time-of-day pattern; notes; and a shareable text summary for your doctor.
- Data is stored only on the phone. Use **Backup / Restore** to save a copy.

Install: open the GitHub Pages link in Safari → Share → **Add to Home Screen**.
